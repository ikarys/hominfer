Know if it runs before you download.

Paste a repository. Every variant gets a verdict from your GPU, your installed engines and your free disk: fits on the GPU, needs a partial offload, doesn't fit, or needs an engine you don't have yet.

Missing an engine? Install it from the page.

llama.cpp, vLLM and others build in the background, with no sudo: the CUDA toolkit comes from NVIDIA's pip wheels, AMD and Intel get a Vulkan build. Missing system tools are listed before anything starts.

Up time, busy time, peak requests and how many sessions run at once, per model and per engine, over a day, a week, three months or any range. The numbers you need to size context and parallel sessions.

Why not Ollama or LM Studio?

I went from Ollama to LM Studio to Unsloth Studio, chasing speed. Then a command-line engine doubled it on the same GPU, and none of those apps could run it. Hominfer started as a single Start button for it, and grew from there.

The fastest engine for your GPU is often one those apps don't run: a fresh llama.cpp build, vLLM, a new project that only has a command line. Hominfer runs whichever you pick, with its own options, from any browser at home.

Install in one line.

The installer uses uv, puts hominfer on your PATH and can set up a systemd service that starts at boot.

Just the launcher

$ curl -LsSf https://raw.githubusercontent.com/ikarys/hominfer/main/install.sh | bash

As a service, reachable from your LAN

$ curl -LsSf https://raw.githubusercontent.com/ikarys/hominfer/main/install.sh | bash -s -- --service --lan

Read the how-to guide or the configuration reference.
